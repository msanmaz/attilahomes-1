# i18n (Turkish / English / Russian) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Turkish / English / Russian i18n to the Next.js 15 App Router site using `next-intl`, including a luxury-styled language switcher in the navbar.

**Architecture:** Use `next-intl` v3 with the `[locale]` dynamic route segment pattern. All public routes move under `src/app/[locale]/`. Middleware auto-detects locale from URL prefix, cookie, or `Accept-Language` header. Default locale is `tr` (no prefix redirect needed). Translations live in `messages/{locale}.json` and are consumed via `getTranslations()` in Server Components and `useTranslations()` in Client Components.

**Tech Stack:** `next-intl@^3`, Next.js 15 App Router, TypeScript strict, Tailwind CSS v4, `next/font/google` (Cormorant Garamond with Cyrillic subset added)

- [ ] **Step 2: Create `src/i18n/request.ts`**

```typescript
import { getRequestConfig } from 'next-intl/server';
import { routing } from './routing';

export default getRequestConfig(async ({ requestLocale }) => {
  let locale = await requestLocale;
  if (!locale || !(routing.locales as readonly string[]).includes(locale)) {
    locale = routing.defaultLocale;
  }
  return {
    locale,
    messages: (await import(`../../messages/${locale}.json`)).default,
  };
});
```

```typescript
  themeColor: [
    { media: "(prefers-color-scheme: light)", color: "#0f0f0f" },
    { media: "(prefers-color-scheme: dark)", color: "#0f0f0f" },
  ],
};

export const metadata: Metadata = {
  title: {
    default: "Attila Homes",
    template: "%s — Attila Homes",
  },
  description:
    "Curated real estate in Istanbul and Bodrum. Selected by Attila Utkucan.",
  openGraph: {

  },
  other: {
    "apple-mobile-web-app-capable": "yes",
    "apple-mobile-web-app-status-bar-style": "black-translucent",
  },
};

export function generateStaticParams() {
  return routing.locales.map((locale) => ({ locale }));
}

export default async function LocaleLayout({
  children,
  params,
}: {
  children: React.ReactNode;
  params: Promise<{ locale: string }>;
}) {
  const { locale } = await params;

  if (!(routing.locales as readonly string[]).includes(locale)) {
    notFound();
  }

  setRequestLocale(locale);
  const messages = await getMessages();

  return (
    <html
      lang={locale}
      className={`${cormorant.variable} ${outfit.variable}`}
    >
      <body>
        <NextIntlClientProvider messages={messages}>
          {children}
        </NextIntlClientProvider>
        <Analytics />
        <SpeedInsights />
      </body>
    </html>
  );
}
```

## Task 7: Build the language switcher component

**Files:**
- Create: `src/components/ui/language-switcher.tsx`

- [ ] **Step 1: Create `src/components/ui/language-switcher.tsx`**

```typescript
"use client";

import { useLocale } from "next-intl";
import { usePathname, useRouter } from "@/i18n/navigation";
import { useTransition } from "react";
import { cn } from "@/lib/utils";

const LOCALES = [
  { code: "tr", label: "TR", name: "Türkçe" },
  { code: "en", label: "EN", name: "English" },
  { code: "ru", label: "RU", name: "Русский" },
] as const;

type Props = {
  /** "inline" = horizontal TR|EN|RU strip (navbar desktop)
   *  "stacked" = vertical list (mobile menu) */
  variant?: "inline" | "stacked";
};

export function LanguageSwitcher({ variant = "inline" }: Props) {
  const locale = useLocale();
  const pathname = usePathname();
  const router = useRouter();
  const [isPending, startTransition] = useTransition();

  function switchLocale(next: string) {
    startTransition(() => {
      router.replace(pathname, { locale: next });
    });
  }

  if (variant === "stacked") {
    return (
      <div className="flex gap-6 mt-2">
        {LOCALES.map((l) => (
          <button
            key={l.code}
            onClick={() => switchLocale(l.code)}
            disabled={isPending}
            className={cn(
              "font-display text-[1.1rem] font-light tracking-[0.2em] uppercase transition-colors duration-300",
              locale === l.code
                ? "text-accent"
                : "text-text-muted hover:text-text-secondary",
            )}
          >
            {l.name}
          </button>
        ))}
      </div>
    );
  }

  return (
    <div
      className={cn(
        "flex items-center gap-0 opacity-80 hover:opacity-100 transition-opacity duration-300",
        isPending && "pointer-events-none opacity-40",
      )}
      aria-label="Language"
    >
      {LOCALES.map((l, i) => (
        <span key={l.code} className="flex items-center">
          {i > 0 && (
            <span className="mx-2 text-text-muted/30 text-[0.6rem] select-none">
              |
            </span>
          )}
          <button
            onClick={() => switchLocale(l.code)}
            disabled={isPending || locale === l.code}
            className={cn(
              "text-[0.62rem] tracking-[0.18em] uppercase font-medium transition-colors duration-300",
              locale === l.code
                ? "text-accent cursor-default"
                : "text-text-muted hover:text-text-secondary",
            )}
          >
            {l.label}
          </button>
        </span>
      ))}
    </div>
  );
}
```

## Notes

**Admin dashboard:** Dashboard routes are under `[locale]` for routing, but the components do NOT use translations. They remain in Turkish. This is intentional — it's an internal tool.

**`localePrefix: "as-needed"`:** Turkish (`defaultLocale`) loads at `/` (no prefix). English loads at `/en/`, Russian at `/ru/`. Change to `"always"` in `src/i18n/routing.ts` if you want `/tr/` prefix too.

**Cyrillic fonts:** `Cormorant_Garamond` now loads the `cyrillic` subset — the display/headline font works for Russian. The body font (`Outfit`) is Latin-only; body-copy Russian text will fall back to the OS system serif (acceptable for v1; replace with `Nunito` or `PT_Sans` if needed).
